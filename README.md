# AI 簡報任務包工作台

把素材整理成可查證、可交接、可交給不同 AI 工具使用的簡報任務包。平台專注內容治理與來源責任，不與 Gamma 正面競爭自動視覺設計。

## MVP 功能

- PDF、DOCX、XLSX、XLS、CSV、TXT、Markdown、PPTX 瀏覽器端解析
- 由 AI 模型產生逐頁大綱（Gemini／OpenAI），支援使用者自備金鑰與伺服器金鑰兩種模式
- 無金鑰時提供本機規則引擎，會明確標示「非 AI 產出」
- 課程 Rules：標題、核心結論、條列字數、數據單位、來源與待補資料
- 逐頁證據大綱編輯、排序、新增與刪除
- 一鍵取得 Gamma 視覺生成、NotebookLM 來源查證、ChatGPT／Claude 內容編修指令
- 完整 Markdown 任務包下載，包含任務卡、品質規則、大綱、來源與風險
- 五種 PowerPoint 骨架風格、自訂 PPTX 主題色與字型擷取
- PptxGenJS 原生文字、色塊與講者備註骨架輸出
- 裝置本機草稿；不保存原始文件內容

## 大綱引擎

平台有兩種產生大綱的方式，畫面上會清楚標示目前使用哪一種。

**AI 模型（建議）**
在「設定任務」步驟填入自己的模型金鑰即可。金鑰只存在該裝置的 localStorage，由瀏覽器直接呼叫模型 API，
不會經過本站伺服器，也不會寫入草稿或任務包。Gemini 提供免費額度且不需信用卡，可到
<https://aistudio.google.com/apikey> 申請。

**本機規則引擎（無金鑰時的後備）**
不呼叫任何模型，只會依標題與段落切出語意區塊，再挑出結論句與支撐證據重新組成投影片。
它不會改寫或歸納文字，也不會替你下判斷，僅適合快速試走流程或處理機密資料。
表格（XLSX／CSV）會轉成「依數值排序的前幾筆重點」，不會逐列貼進投影片。

## 組織部署（可選）

若不希望同仁各自管理金鑰，可複製 `.env.example` 並在伺服器環境設定 `GEMINI_API_KEY` 或 `OPENAI_API_KEY`。
使用者金鑰欄位留空時，會改由 `/api/generate` 使用伺服器金鑰生成。兩者都沒有時才退回本機規則引擎。

## 安全邊界

原始檔案在瀏覽器解析。使用者自備金鑰時，來源文字與金鑰只在瀏覽器與模型供應商之間傳輸；
使用伺服器金鑰時，`/api/generate` 只接收擷取後的文字。資料分級選「機密」會阻擋所有外部模型。
金鑰一律不得放入 `NEXT_PUBLIC_*` 或版控。送往模型的來源內容以 `<source>` 標籤包覆，
並在系統提示中要求模型將其視為資料而非指令，以降低提示注入風險。
正式企業版仍需加入 SSO、惡意檔案掃描、集中式稽核、外部模型傳輸政策及定期刪除機制。

## 開發與驗證

```bash
pnpm install
pnpm dev        # 本機開發
pnpm build      # 產出
pnpm lint
pnpm typecheck
```

PowerPoint 下載在瀏覽器端產生，不需上傳產出檔。
